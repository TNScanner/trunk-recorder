<h1 align="center">📡 Rdio Scanner Uploader (Routing Edition)</h1>
<h3 align="center">Enhanced Trunk Recorder uploader with advanced per-talkgroup routing</h3> <p align="center"> <strong>Fully compatible with the original uploader — now with routing support.</strong><br> Route specific talkgroups to different Rdio system IDs with fallback logic and clean debug output. </p> <hr>
<h2>✨ Features</h2>
<ul> <li><b>Per-Talkgroup Routing</b> – Override the system ID for specific TGs.</li> <li><b>Fallback System</b> – TGs not matching any route go to the default <code>systemId</code>.</li> <li><b>Wildcard Routes</b> – Use <code>"talkgroups": []</code> to match everything not already matched.</li> <li><b>Lite Debug Mode</b> – Clean routing logs without excessive output.</li> <li><b>Backward Compatible</b> – Remove routes and it works identically to the original uploader.</li> </ul> <hr>
<h2>🧠 Routing Logic Overview</h2>
<table> <thead> <tr><th>Condition</th><th>Uploader Behavior</th></tr> </thead> <tbody> <tr><td>Talkgroup appears in a route</td><td>Use that route's <code>systemId</code></td></tr> <tr><td>No exact match, wildcard route exists</td><td>Use wildcard route <code>systemId</code></td></tr> <tr><td>No routes match</td><td>Use fallback <code>systemId</code></td></tr> <tr><td>No routes defined</td><td>Behaves exactly like the original uploader</td></tr> </tbody> </table> <hr>
